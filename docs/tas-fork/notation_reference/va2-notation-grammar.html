03

Formal grammar

# PEG-style; ordered choice; all keywords case-insensitive.
# Pre-pass: stitch multi-row combos; protect multi-word assist names; normalize WS + '//' to '/'.

Sequence   <- Step (StepSep Step)* StepSep?          # trailing sep tolerated
StepSep    <- ('/' / WS)+                             # '/' OR whitespace end a step; runs = empty steps

Step       <- RepeatGrp / EmptyStep / Annotation / InputStep
EmptyStep  <- &(StepSep / EOF)                        # yields 1 neutral frame
RepeatGrp  <- '[' Sequence ']' '*' NUM                # repeat the expanded group N times (resolved)

InputStep  <- Neutral / Atoms
Neutral    <- 'n' NUM?                                # n = 1 frame · n65 = 65 frames

Atoms      <- Atom ('+' Atom)*                        # '+' fuses atoms onto the same frame(s)
Atom       <- MotionAtom / DirBtnAtom / BtnAtom / AssistAtom / Start
MotionAtom <- DIGIT DIGIT+ Buttons? Assist? Dur?      # ≥2 digits: 1 frame/digit; last carries the rest
DirBtnAtom <- DIGIT Buttons Assist? Dur?              # 6pp18 = dir + buttons, held
            / DIGIT Assist Dur?                        # 6a1
            / DIGIT Hold                               # 6-29 = held direction
            / DIGIT                                    # 1 frame
BtnAtom    <- Buttons Assist? Dur?                    # pp / hk140
Start      <- 'start' NUM?

Buttons    <- ('pp' / 'kk' / 'lp' / 'hp' / 'lk' / 'hk')+   # pp = LP+HP · kk = LK+HK
Assist     <- 'assist'('1'/'2') / 'a'('1'/'2')        # deterministic → A1/A2
            / 'assist-'('a'/'b') / 'assistb'           # slot-vs-type ambiguous → DEFERRED (F2)
            / NAME '-' ('a'/'b'/'y') / KnownCharName   # named → NEEDS USER (F1/F12)
Hold       <- ('-' / '_') NUM
Dur        <- NUM                                     # only after buttons, or via Hold
DIGIT      <- [1-9]                                   # standard numpad · 5 = neutral · 9 = UP-RIGHT (resolved)

The normative disambiguations

  1. Motion vs held direction — the -/_ is the switch. A bare run of ≥2 digits is a motion (1 frame per digit); a separator before a number forces it to be a duration. 236 = 3-frame QCF; 6-29 = right held 29f; 2369-4 = motion with the final direction held 4f.
  2. The - never collides with names. <digit>-<number> = hold; <letters>-<a|b|y> = named assist. Decide by what flanks the dash.
  3. A button after the first digit locks it as a direction. 6pp18 = dir 6 + PP held 18f — never 6 then pp18. A motion needs ≥2 consecutive digits before any button.
  4. Trailing-number binding. The final integer is the duration of the atom's last frame — after buttons (2hk29, 236hk12), or after a bare direction/motion only via -/_. A number with no preceding button and no separator is motion digits, never a duration.
  5. Whitespace separates steps (line-wrap artifact) — the one divergence from the engine. Exception: the space inside a multi-word assist name (Ruby Heart-B) — protect via a longest-match character-name table in the pre-pass.
  6. + fuses onto the same frame(s). 4+lp+lk+start37 = LEFT+LP+LK+START held 37f. A mid-step duration binds to the button it trails: pp10+Cammy-A = PP held 10f, with the assist on that step.

Round-trip contract

CategoryBehavior
LosslessDurations/RLE (2hk29 ⇄ 29×(DOWN|HK)) · neutrals (nN ⇄ mask-0 runs, modulo 255-chunk merging) · the whole digital canon-bit domain (8-way + 6 buttons + START + A1/A2).
Canonical-choice on exportMotion vs per-frame text (236 vs 2/3/6) — both re-expand identically; exporter policy: emit motion notation only on a strong known-motion match, else explicit RLE steps.
Lossy by constructionNamed-assist character identity (export always emits a1/a2; names are not part of the per-frame model) · annotations, repeat-groups and typos resolve at import and never regenerate · analog fidelity is out of scope (the dialect is digital-only).
invariant
For codec-generated text T: expand(parse(T)) == frames — per-frame canon-mask equality, frame count included (mirror tas_macro::Probe, tasmacro.h:64). For imported hand-authored text: every step must parse to a definite mask+count with zero unresolved needs-user flags — surface every flag rather than silently emitting bits. Round-trip equality is guaranteed on export, not import.
